# Eliel Dutra — Terapeuta TRG e Psicanalista

Site institucional estático (HTML, CSS e JavaScript puros, sem etapa de build).

> Da raiz da dor à liberdade de ser.

## Estrutura

- `index.html` — conteúdo e estrutura das seções
- `styles.css` — identidade visual, layout mobile-first e animações
- `script.js` — linha-raiz de scroll, animações, autoavaliação (quiz) e links do WhatsApp
- `assets/` — logo e foto

## Ajustes rápidos

- **WhatsApp:** constante `WHATSAPP_NUMBER` no topo de `script.js`
- **Perguntas e resultados do quiz:** `QUESTIONS` e `RESULTS` em `script.js`
- **Instagram:** links em `index.html` (seção Contato e rodapé)

## Rodar localmente

Abra `index.html` por um servidor local qualquer, por exemplo:

```bash
npx serve .
```
